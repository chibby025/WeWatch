## ⚖️ Legal Foundation

### 1. DMCA Safe Harbor Compliance (17 U.S.C. § 512)

WeWatch qualifies for DMCA Safe Harbor protection under Section 512(c) by implementing:

#### ✅ **Requirements Met:**
- **Designated DMCA Agent:** Registered with U.S. Copyright Office
- **Takedown Policy:** 24-48 hour response time for valid DMCA notices
- **Repeat Infringer Policy:** Three-strike system with permanent ban
- **No Actual Knowledge:** Content declaration system prevents constructive knowledge
- **Financial Benefit Test:** Controlled through verification and declaration systems


**ACTION REQUIRED FOR FUNDING:**

### 2. Multi-Tier Protection System

WeWatch implements layered legal protection based on session type:

#### **Tier 1: Lecture Halls (PAID - ZERO RISK)**
- **Legal Basis:** Educational use, transformative content
- **Ticketing:** Fully enabled, no restrictions
- **Platform Cut:** 25%
- **Risk Level:** ✅ **NONE** - Standard SaaS model

**Justification:**
- Teachers charging for classes = Udemy, Coursera model
- Educational content has fair use protection
- No copyright concerns for original lectures

#### **Tier 2: Cinema/Video (PAID - CONTROLLED RISK)**
- **Legal Basis:** Creator-owned content + Content Declaration System
- **Ticketing:** Enabled with declaration requirement
- **Platform Cut:** 30% (risk premium for non-verified)
- **Risk Level:** ⚠️ **LOW** - Protected by indemnification

**Protection Mechanisms:**
1. **Content Declaration Modal** (implemented)
   - User certifies ownership under penalty of perjury
   - Creates legal record with timestamp and IP
   - Establishes indemnification chain

2. **Four Content Categories:**
   - Original Content (user-created)
   - Licensed Content (user has rights)
   - Educational/Transformative Use
   - Public Domain

3. **Legal Agreement Text:**
   ```
   "By submitting this declaration, I certify under penalty of perjury that:
   - I am the copyright owner OR have permission to monetize this content
   - I indemnify WeWatch against any copyright claims
   - I understand false declarations result in account suspension and legal action"
   ```

#### **Tier 3: Free Watch Parties (FREE - DMCA PROTECTED)**
- **Legal Basis:** DMCA Safe Harbor 512(c)
- **Ticketing:** Disabled (free only)
- **Platform Cut:** 0% (ad revenue instead)
- **Risk Level:** ✅ **SAFE** - YouTube/TikTok model

**Protection Mechanisms:**
- DMCA takedown compliance
- User Terms of Service prohibiting piracy
- 500MB file size limit (discourages full movies)
- Copyright disclaimer on upload
- No financial benefit from infringing content

## 🛡️ Indemnification Structure

### Platform Protection Hierarchy

```
Copyright Claim Filed
        ↓
1. User's Content Declaration provides first-line indemnity
        ↓
2. User's signed agreement requires them to defend/indemnify WeWatch
        ↓
3. WeWatch immediately removes content (DMCA compliance)
        ↓
4. WeWatch provides user declaration to claimant as evidence
        ↓
5. Legal liability shifts to declaring user
```

### Key Legal Principles

**1. Indemnification Clause (User Agreement):**
```
User agrees to indemnify, defend, and hold harmless WeWatch, its officers,
directors, employees, and agents from any claims, damages, losses, liabilities,
and expenses (including attorney's fees) arising from:
(a) User's breach of content ownership representations
(b) User's violation of any third-party rights
(c) User's use of the WeWatch platform
```

**2. Limited Liability (Terms of Service):**
```
WeWatch acts as a platform provider only. We do not screen or verify content
ownership beyond user declarations. Maximum liability limited to fees paid
by user in preceding 12 months.
```

**3. Verification of Identity:**
- Email verification (required)
- Payment method verification (credit card/bank for withdrawals)
- IP address logging (all declarations)
- User agent recording (device/browser)
- Creates traceable identity for legal process

## 💼 Response to Copyright Claims

### Standard Operating Procedure

**Phase 1: Receipt of Complaint (0-2 hours)**
```
1. Log complaint in database
2. Auto-disable content immediately
3. Notify user via email
4. Refund all ticket purchasers automatically
5. Flag user account (strike system)
```

**Phase 2: Investigation (2-24 hours)**
```
1. Review user's content declaration
2. Check for counter-notice from user
3. Assess validity of claim
4. Document all evidence
```

**Phase 3: Resolution (24-48 hours)**
```
Valid Claim:
- Permanent content removal
- Strike added to user account
- User notified of violation
- Claimant notified of removal

Invalid Claim (User provides proof):
- Counter-notice filed
- Content restored after 10-14 days (DMCA statutory period)
- User receives apology credit

Repeat Offender (3 strikes):
- Permanent account ban
- Forfeit of pending earnings
- IP/email blacklist
```

**Phase 4: Legal Escalation (if needed)**
```
1. Provide user's declaration to claimant
2. Assert indemnification rights
3. Refer claimant to user directly
4. Engage legal counsel if sued
5. File motion to dismiss (platform immunity)
```

## 📄 Database Schema Requirements

### Content Declarations Table

```sql
CREATE TABLE content_declarations (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    session_id INTEGER REFERENCES watch_sessions(id),
    
    -- Declaration Details
    content_type VARCHAR(50) NOT NULL, -- 'original', 'licensed', 'educational', 'public_domain'
    content_title VARCHAR(255) NOT NULL,
    content_description TEXT NOT NULL,
    production_year INTEGER,
    rights_holder VARCHAR(255) NOT NULL,
    additional_info TEXT,
    
    -- Legal Record
    agreed_to_terms BOOLEAN NOT NULL DEFAULT false,
    declaration_timestamp TIMESTAMP NOT NULL DEFAULT NOW(),
    ip_address INET NOT NULL,
    user_agent TEXT NOT NULL,
    
    -- Verification Status
    is_verified BOOLEAN DEFAULT false,
    verified_at TIMESTAMP,
    verified_by INTEGER REFERENCES admin_users(id),
    verification_notes TEXT,
    
    -- Compliance Tracking
    dmca_complaints INTEGER DEFAULT 0,
    last_complaint_date TIMESTAMP,
    status VARCHAR(50) DEFAULT 'active', -- 'active', 'disputed', 'removed'
    
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_declarations_user ON content_declarations(user_id);
CREATE INDEX idx_declarations_session ON content_declarations(session_id);
CREATE INDEX idx_declarations_status ON content_declarations(status);
```

### DMCA Complaints Table

```sql
CREATE TABLE dmca_complaints (
    id SERIAL PRIMARY KEY,
    
    -- Complaint Details
    complainant_name VARCHAR(255) NOT NULL,
    complainant_email VARCHAR(255) NOT NULL,
    complainant_address TEXT,
    
    -- Target Content
    session_id INTEGER REFERENCES watch_sessions(id),
    content_url TEXT NOT NULL,
    infringing_material_description TEXT NOT NULL,
    
    -- Copyright Claim
    copyrighted_work_description TEXT NOT NULL,
    copyright_registration_number VARCHAR(100),
    
    -- Legal Attestation
    good_faith_belief TEXT NOT NULL,
    accurate_info_attestation BOOLEAN NOT NULL,
    signature VARCHAR(255) NOT NULL,
    signature_date DATE NOT NULL,
    
    -- Processing
    received_at TIMESTAMP DEFAULT NOW(),
    status VARCHAR(50) DEFAULT 'pending', -- 'pending', 'processing', 'removed', 'counter_notice', 'restored'
    processed_at TIMESTAMP,
    processed_by INTEGER REFERENCES admin_users(id),
    
    -- User Response
    counter_notice_received BOOLEAN DEFAULT false,
    counter_notice_text TEXT,
    counter_notice_date TIMESTAMP,
    
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_complaints_session ON dmca_complaints(session_id);
CREATE INDEX idx_complaints_status ON dmca_complaints(status);
```

### User Strikes Table

```sql
CREATE TABLE user_copyright_strikes (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    dmca_complaint_id INTEGER REFERENCES dmca_complaints(id),
    
    strike_number INTEGER NOT NULL, -- 1, 2, or 3
    strike_reason TEXT NOT NULL,
    strike_date TIMESTAMP DEFAULT NOW(),
    
    -- Status
    is_active BOOLEAN DEFAULT true,
    expires_at TIMESTAMP, -- Optional: strikes expire after 6-12 months
    
    -- Ban Tracking
    resulted_in_ban BOOLEAN DEFAULT false,
    ban_date TIMESTAMP,
    
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_strikes_user ON user_copyright_strikes(user_id);
CREATE INDEX idx_strikes_active ON user_copyright_strikes(is_active);
```
